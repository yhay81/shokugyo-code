# Product metrics

`npm run metrics` reports non-QA unique users, category selectors, successful and no-result search events, hierarchy changers, comparison users, copiers, official-detail openers, and returning comparison users. Seven-day searcher and copier counts show early movement.

A successful search is emitted only when the current local query and filters return at least one record. No query, job description, category, or classification code enters telemetry.
